AI 引擎日报｜2026-11-07

2026-11-07北京时间

今天的增量不在“再接一个聊天框”，而在引擎开始把代理如何找接口、看结果和被人接管做成底层能力。

Origin Engine：把代理的眼睛与索引做进引擎

这个新发现的 MIT 开源引擎用 Rust/wgpu 承担运行时，游戏逻辑写 TypeScript；同一项目既能在浏览器以 WebAssembly 运行，也能在原生无头执行器里跑。11 月 7 日加入的 pick_ui 会返回鼠标位置下的界面元素、源码行和命中的样式规则，前一天的 og api find 又把关键词检索与本地语义索引合并，方便代理先找到正确接口，再用截图、世界转储和确定性回放验收结果。代码已公开，能直接研究；但仓库创建不足一个月，尚无稳定版本，也没看到大型成品或独立性能验证。仓库（持续更新） · 界面探针提交（2026-11-07） · API 检索提交（2026-11-06）

Genex 0.1.34：长任务终于可以当场插话

Genex 的新版本允许人在 Loop 运行期间发消息，直接终止当前主代理回合并先得到回答，且覆盖 Unreal、Unity、Godot 和网页项目；同时，无法启动的步骤会把原因交回主代理决策，减少长流程静默卡住。对多代理造游戏来说，这比事后撤销更实用：方向不对时可立即纠偏。安装包已发布，仍属快速迭代的早期桌面产品，官方说明不等于跨引擎稳定性已被独立验证。发布说明（2026-11-06） · 中断回合实现（2026-11-06）

我的判断： AI 原生引擎的分水岭正从“能生成代码”移到“代理能观察、定位、保存可复核证据，并在人类介入时安全停手”。这类控制面会比单次生成速度更影响真实可用性。
