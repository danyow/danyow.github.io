电话语音日报

电话语音日报｜2026-09-24

2026-09-24北京时间

今天最有价值的变化，是“语音前台 + 后台长任务 + 可穿戴入口”开始真正合流；但确认佩戴后再插播、跨第三方播放器压音/恢复、未听见后再电话升级，仍没有现成方案一口气做完。

  1. Qwen Audio Agent v2.0 重做编排层，统一客户端协议并接入 ACP/A2A 后台 Agent；前台语音和后台任务可并行，能查进度、取消、跨会话保留记忆，论文还明确把“语音被打断”和“后台任务被取消”分开。它已经适合作为长任务“后台脑”，而且任务完成后能回到当前会话继续追问，比单纯把语音会话拉长更接近随身助手。限制是远程移动访问仍不等于成熟耳机入口，佩戴检测、锁屏常驻和跨 Spotify/有声书自动压音恢复都未完整验证。 Release · 论文

  2. Ray-Ban Meta Audio + Muse 更接近消费级“边听边用 Agent”：Meta 9月23日发布开放式音频眼镜，可听音乐/播客、接电话，并称可免手持与 AI 助手交互最长约12小时，同时宣布把 Muse 个人 Agent 接入 AI 眼镜。Meta 眼镜体系已有“Hey Meta”唤醒，这说明音乐入口、免手持语音和任务 Agent 正在同一硬件上汇合；但官方没有证明主动插播优先级、播放位置恢复、未读确认和电话兜底升级，也没有通用的“已佩戴且确实听见”信号。 官方 · 唤醒

  3. 电话兜底今天主要是稳定性修补。 Bolna 0.10.255 增加 Deepgram 零数据留存开关，0.10.256 修复多语音池各线路独立鉴权，分别对应隐私留存和多供应商线路错配风险。线路侧没有突破：Twilio 当前仍明确写着大陆 +86 外呼不支持；香港、新加坡移动外呼页面价约为 $0.0546 和 $0.0578/分钟。也就是说，电话入口依旧可以作为港新及其他支持地区的兜底，但不能从“支持中文”推断可达大陆手机。 255 · 256 · 中国规则

最值得试：先把 Qwen Audio Agent v2.0 当后台脑，再单独补手机耳机状态与播放器协调层；组合路线还没做整体实测。
