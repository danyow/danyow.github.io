电话语音日报

电话语音日报｜2026-09-20

2026-09-20北京时间

今天最值得补录的不是新语音模型，而是一套已经落到消费耳机上的交互：FreeBuds 7 的官方文档很接近“确认佩戴后耳内插播、用户再追问”的目标；但它仍是华为/豆包生态能力，不是可直接接入自建 Agent 的开放入口。

1. HUAWEI FreeBuds 7：旧项目补录，消费耳机已做到“佩戴→播报→语音选择→追问”

华为官方称，FreeBuds 7 可做打车、登机、外卖等智慧播报，并对播报内容继续问答；支持页进一步写明，HarmonyOS 6.1+ 下需“耳机连接并佩戴”，才能用语音选择是否收听、暂停或中断消息。AI 键还可唤醒小艺，Android/iOS 则可联动豆包。它已经补上佩戴门槛、耳内通知和会话入口，但没有证据表明能跨第三方音乐/有声书 App 自动降低原音频并精确恢复播放位置，也没有公开接口把同一事件交给自建 Agent、保留未读确认后再电话升级。

产品页 · 智慧播报 · AI 键

2. Bolna 0.10.244：后台语音 Agent 路由更早开始，但仍只是“脑后面的管线”

9 月 18 日的 0.10.244 将图路由调用改为流式，并按函数名尽早分发。对耳机入口和电话兜底共用同一 Agent 的架构，这能减少“用户刚说完，系统还在等路由决定”的停顿。代码可自部署，但它不负责耳机佩戴识别、手机后台唤醒、文字未读、长任务持久化或电话线路，需要与移动端状态机和 PSTN/SIP 层组合。

Release

电话兜底本次复核没有看到条件变化：Twilio 官方仍写明中国大陆号码入站、出站均不支持；香港和新加坡仍支持 PSTN 双向，但本地外呼 caller ID 有当地合规限制。适合当海外、港新路线参考，不能外推到大陆号码。
